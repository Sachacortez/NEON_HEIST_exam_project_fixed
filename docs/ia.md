# Uso de IA

Se utilizó un agente de IA como asistente durante el desarrollo del proyecto.

## Solicitudes realizadas

- Diseñar un juego de dos jugadores que cumpla las restricciones del examen.
- Proponer reglas sencillas para movimiento, ataque, defensa, energía y recursos.
- Generar una estructura React + TypeScript + Express + TypeScript.
- Preparar pruebas E2E con Playwright.
- Preparar workflows de GitHub Actions.
- Preparar documentación técnica y de deployment.

## Código incorporado

Se incorporaron partes de código generadas o revisadas con asistencia de IA para la interfaz React, la API Express, las reglas del juego, Playwright, CSS, TypeScript y documentación.

## Verificación del estudiante

Antes de la entrega, el estudiante debe ejecutar localmente:

```bash
npm install
npm run lint
npm run build
npm test
```

También debe revisar el código y poder explicar las reglas principales, los componentes React, los endpoints y la función `fetch`.

## Modificaciones manuales

Cualquier modificación hecha por el estudiante durante la preparación de la defensa debe anotarse aquí con una breve descripción y la razón del cambio.

> No se declaran pruebas o resultados que no hayan sido ejecutados y comprobados por el estudiante.
